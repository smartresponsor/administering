= 069 Composer Package Evidence Boundary

Administering is a standalone Symfony component. The canonical platform baseline is an explicit Composer dependency, while optional runtime-scope components remain external evidence discovered from runtime inventory.

== Rule

Administering may read component package names from:

* `APP_RUNTIME_SCOPE`
* `composer.json`
* `composer.prod.json`
* `config/kernel/runtime_scope.lock.php`
* `config/kernel/runtime_scope.prod.lock.php`
* `config/runtime-scope/bundle_catalog.php`

Administering must directly require `cruding/crud`, `collectioning/collection`, `tabling/table`, `viewing/view`, `interfacing/interface`, `objecting/object`, and `easycorp/easyadmin-bundle` in `composer.json`. Other runtime-scope packages remain optional evidence and must not become root dependencies unless Canonization explicitly promotes them to the platform baseline.

Development baseline packages use sibling Composer `path` repositories with `options.symlink: true`; `composer.prod.json` uses packaged/VCS dependencies and contains no sibling path repositories.

== Before

`composer.json` required `configuring/config` and also declared a sibling path repository for `../Configuring`.

That made Configuring an install-time dependency of Administering, even though Administering only needs to inspect runtime-scope evidence.

== After

`configuring/config` is removed from `require`.

The sibling path repository is removed.

`configuring/config` may remain only as non-installing Composer suggestion metadata and as external host evidence when the host application chooses to install Configuring.

== Guard

The architecture suite now includes:

* `tools/inspection/administering-composer-package-boundary-guard.php`
* `tools/inspection/administering-composer-package-boundary-guard.ps1`

The guard rejects:

* non-baseline runtime-scope packages from `config/runtime-scope/bundle_catalog.php` in root `require` or `require-dev`;
* sibling component path repositories outside the Canonization-permitted helper contour;
* baseline sibling repositories that are not Composer `path` repositories with `options.symlink: true`.

This keeps optional runtime-scope packages as evidence while preserving the explicit Canon022 platform baseline and Canon023 development wiring.
