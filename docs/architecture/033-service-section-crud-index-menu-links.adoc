= Service Section Route Menu Links

Administering left-menu service-section roots must open stable service-section route screens.

== Canon

* `src/Service/<Section>` defines a left-menu section.
* The section menu item must be built with `MenuItem::linkToRoute(...)` pointing at `administration_service_section_tools`.
* The linked route must resolve to the service-section tool dashboard for the selected section.
* Generic fallback/frontend links are forbidden for service-section roots.

== Reason

A service-section root is the stable entry point for a tool area. The sidebar must not point to internal review, apply, diagnostic, or fallback frontend routes. Those tools live inside the section screens.

== Empty sections

Empty `src/Service/<Section>` directories are valid planned sections. They use the generic `AdministrationServiceSectionRecordCrudController` until a section-owned CRUD anchor exists.
