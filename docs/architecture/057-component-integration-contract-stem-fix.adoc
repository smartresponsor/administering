= Component Integration Contract Stem Fix

Administering component integration contracts use the `Administration*` owner stem.

Canonical names:

* `AdministrationComponentIntegrationContractInterface`
* `AdministrationComponentIntegrationContractRegistry`
* `AdministrationAccessingComponentIntegrationContractProvider`
* `AdministrationAccessingComponentIntegrationContractProvider`
* `AdministrationRollingComponentIntegrationContractProvider`

Old `ComponentIntegrationContract*`, `AccessingComponentIntegrationContract*`, and `RollingComponentIntegrationContract*` names are deleted.
